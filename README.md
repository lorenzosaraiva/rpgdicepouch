# RPG Dice Pouch — Privacy Policy

A small, static privacy policy website for RPG Dice Pouch, developed by Lorenzo Saraiva. It covers local data, optional Supabase accounts and cloud sync, optional RevenueCat purchases, retention, deletion, and privacy contact details.

## Enable GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then click **Save**.
4. Wait for GitHub's Pages deployment to complete.

Privacy policy URL after publishing:

**https://lorenzosaraiva.github.io/rpgdicepouch/**

The data deletion section is directly linkable:

**https://lorenzosaraiva.github.io/rpgdicepouch/#delete-data**

GitHub's setup documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Files and updates

- `index.html`: the complete policy, readable without JavaScript.
- `styles.css`: mobile-friendly layout and print styles.
- `assets/d20.png`: original app artwork.
- `assets/outfit-latin.woff2`: self-hosted Outfit variable font.
- `assets/OFL.txt`: the font's SIL Open Font License.
- `.nojekyll`: serves the static files directly on GitHub Pages.

No installation, build command, backend, or JavaScript is required. All assets use relative paths, so they work under the repository's GitHub Pages path. The website sets no cookies or browser storage and contains no analytics or external embeds. GitHub still processes hosting requests as described in the policy.

To update the policy, edit `index.html`, update the visible date and its `datetime` value, and push to `main`. Once Pages is enabled, GitHub automatically publishes updates. Keep the policy aligned with the actual shipped app and its store privacy disclosures as online features change.
